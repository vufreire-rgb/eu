# Draw My Life — Vinicius Freire

Apresentação interativa (22 slides) em um único arquivo: abra `index.html` no navegador ou publique-o em qualquer hospedagem estática.

- **Navegação:** deslize, botões ← →, teclado (setas, espaço, Home/End), `P` = reprodução automática, `N` = narração.
- **Narração:** painel de legenda (botão "Narração"); botão "Voz" lê em pt-BR com a voz do navegador, nunca inicia sozinho.
- **Movimento reduzido:** respeita `prefers-reduced-motion` (tudo aparece desenhado, sem animações).
- **Links do slide final:** preencha o objeto `LINKS` no início do `<script>` em `index.html`. Enquanto vazios, os botões avisam que o link ainda não foi configurado.
